# RUNUP Learn · site-knowledge

English · [中文](README.md)

Website project for `learn.paobu.org`: nine fixed topics, article lists and detail pages, topic collections, local search, language entry points, and a local 404. Knowledge prose, sources, and review data come from `running-handbook/knowledge/`; shared layouts, themes, routing, and content validation come from the versioned `@paobu/core` artifact.

## Layout

```text
src/pages/                [...locale] home, article list/detail, topic collections, search, and 404
src/lib/content.ts        Site content loading (including the preview switch)
src/lib/view.ts           Topic copy and knowledge detail formatting
scripts/sync-core.mjs     Verifies and syncs the core tgz from ../paobu-core/core-dist
scripts/postbuild.mjs     Pagefind index and static output checks
vendor/paobu-core.tgz     Locked core artifact (gitignored; rebuilt by core:sync before install)
core.lock.json            Core artifact version and SHA-256
content.lock.json         Local tree lock for the two content repositories
```

## Local Run

All six projects live under one parent directory. First ensure `paobu-core` has produced `core-dist/paobu-core-0.3.0.tgz`:

```bash
cd paobu-core
node scripts/pack-core.mjs

cd ../site-knowledge
node scripts/sync-core.mjs
pnpm install
pnpm test:content
pnpm check
pnpm build
pnpm dev
```

- Development: `http://localhost:4322`.
- Preview build: `pnpm preview`, `http://localhost:4422`.
- Content validation: `pnpm test:content`.
- Type check: `pnpm check`.
- Unit tests: `pnpm test`.

Production builds must set the three origins and the review switch explicitly:

```bash
PUBLIC_ROUTES_ORIGIN=https://paobu.org \
PUBLIC_KNOWLEDGE_ORIGIN=https://learn.paobu.org \
PUBLIC_TOOLS_ORIGIN=https://tools.paobu.org \
PREVIEW_UNREVIEWED=0 pnpm build
pnpm check:production
```

## Shared Core and Content Lock

Core source changes only in `paobu-core`. After `node scripts/pack-core.mjs` there, run `node scripts/sync-core.mjs && pnpm install` in this repository. All three sites must use the same version and SHA-256; keep older tgz artifacts for rollback.

The content lock is generated by `node scripts/content-lock.mjs` at the handoff root and covers `marathon-trail-running-races` (`content/`, `data/`, `assets/`) and `running-handbook` (`knowledge/{content,data,assets}`, `tools/{content,data,assets}`). It currently pins route repo `7cc63ab7…` and handbook `1e008e39…`.

## Review and Scope

- Knowledge entities received **AI-assisted editorial review**, not independent or professional medical, nutrition, or coaching review; pages show only the neutral “跑起来编辑部 / RunUp Editorial” byline.
- Health articles include care-seeking boundaries, emergency signals, and out-of-scope notes; they do not provide diagnosis or medication advice.
- Preview builds may show the unreviewed banner; production builds must use `PREVIEW_UNREVIEWED=0`.
- The live site has been released. All six repositories have been created or renamed under `paobuorg` and pushed; Pages builds from this repository's `main` workflow.
